1.2 开篇结论：五个核心问题

1. H1整体经营是否好于2025年H1？

整体好于去年同期，双品牌跑赢大盘。大盘增长38%，双品牌增长60%。翔龙品牌实现人数、收入、毛利同步增长，利润改善明显；国旅品牌成交人数小幅下滑，但GMV和单客收入保持增长。

2. 收入、人数与毛利是否同步增长？

翔龙品牌：收入、人数、毛利同步提升。人数增长17%，收入增长23%，毛利增长281%。收入增速高于人数，毛利增速高于收入，单客收入和单客毛利均有提升；毛利率由2%提升至6%，经营效益明显改善。

国旅品牌：收入增长，但人数承压。成交人数下降6%，GMV增长5%，单客收入增长12%。收入增长主要来自客单提升。线上成交人数下降14%，线下GMV增长16%，线下是当前唯一正增长渠道。

3. 翔龙品牌与国旅品牌分别贡献了多少增长和毛利？

翔龙品牌是增长和利润改善的主要贡献品牌。ERP收入同比增加4,669万（其中携程平台收入同比增5,519万）；毛利额同比增加1,227万，毛利率由2%提升至6%。收入增长与利润改善同步，贡献突出。

国旅品牌收入保持增长，但成交规模未同步提升。携程平台收入同比增加415万，成交人数下降，增长主要来自客单提升。线下是当前稳定成交的核心支撑，线上GMV下降4%是主要压力点。

4. 增长质量如何？

翔龙品牌：增长质量改善明显。毛利率由2%提升至6%，单客毛利由437元提升至1,415元。

国旅品牌：收入结构改善，但规模下滑风险需关注。人数下降、客单提升，反映收入增长更多来自产品结构和价格带变化。线上成交人数下降14%，说明产品供给、价格竞争力和流量转化均存在问题，需要尽快修复。

5. H2目标缺口与核心抓手是什么？

翔龙品牌：提升资源收益，保持分销增长质量。人数缺口约4,679人，达成率71%；GMV缺口约8,845万。H2重点是基于已采购机位优化产品组合、销售节奏和渠道结构，提升机位使用效率、控制机损费用。暑期阶段重点做好团队交付和服务保障。

国旅品牌：稳住暑期交付，补强淡季产品和成交规模。人数缺口约2,122人，达成率46%；GMV缺口约3,340万。暑期已进入出团阶段，首要任务是保障团队交付和服务体验。后续重点补强淡季产品线、修复线上成交、提升线下门店转化，并推动重点省份和重点区域市占恢复。虽然携程平台整体UV下降57%，但北京国旅品牌UV逆势增长32%、CR表现稳定，仍具备流量转化基础；下一步关键是提升流量转化，带动成交规模恢复。

3. 逐类深挖真实原因

3.1 成团问题——不是"运气不好"，是收客管理失控

数据信号真实原因
  • Q2成团问题7单（成团后不成团6单+常规不成团1单），全部发生在行前
  • 7月成团问题暴增至15单，其中"一般不成团"13单
  • 6月"已成交(全部退订)"的诋毁率高达24%
  • 收客监控滞后：临期才通知不成团
  • 成团承诺随意：有订单承诺已经成团，结果反悔
  • 转团补偿不到位：转团优惠仅按5%违约金核算，客人认为"不是补偿是套路"

3.2 行程体验问题——酒店是最大短板

数据信号真实原因
  • Q2酒店相关不满6单，7月3单
  • 涉及线路：法意瑞、俄罗斯、英爱、巴尔干、东欧——跨线路共性
  • 酒店标准模糊："4钻酒店"实际"如家水平"
  • 披露与实物不符：行程单承诺与实际入住不一致
  • 没有酒店黑名单：重复出现问题的酒店仍在继续使用

3.3 价格公平问题——同团不同价，线下门店渠道让利反噬国旅品牌

数据信号真实原因与核心诉求
  • Q2同团不同价5单+单房差定价1单，合计6单（23%）
  • 所有同团不同价备注均指向"线下门店订单让价，判定为国旅品牌责任"
  • 门店返佣不透明：门店私下让利返佣
  • 价格监控缺失：无法实时核查门店与客人的实际签约价
核心诉求：将诋毁从供应商责任调整为门店责任，不计入国旅品牌服务交付体验考核

3.4 退订损失不满——合同收损合法合规，问题在于"客人预期管理不足"

数据信号真实原因与核心诉求
  • Q2共5单临时退订客人不满
  • 投诉组已判定客人责任
  • 法律层面：按合同收损完全合规
  • 投诉判定：客人责任，已明确
  • 服务交付体验考核：诋毁计入国旅品牌，被"误伤"
  • 客人感受："我不去还要扣我钱"，体验极差
核心诉求："投诉组已判定客人责任"的订单，不应计入供应商服务交付体验考核

3.5 应急能力问题——不可抗力暴露机制短板

数据信号真实原因

  • 关键词："携程没有及时调整""滞留机场无人管"
  • 信息监控滞后：火山6月26日活跃，7月5日升红色预警，7月6日仍安排客人前往机场
  • 预案缺失：航班取消后响应慢，客人被迫滞留

核心结论

国旅品牌服务交付体验的恶化不是单点服务问题，而是成团管理、酒店管控、渠道价格、应急响应四个底层能力的系统性缺陷。其中成团问题在7月已占诋毁订单的56%，是最紧迫的改善点。5分好评率从82%跌至29%，说明满意客户的沉默和流失同样需要关注。短期聚焦成团预警和酒店清单，中期建设班期看板和价格监控，长期将服务交付体验纳入产品绩效考核，才能形成完整的改进闭环。

2. 增长来源

翔龙品牌
增长主要由西欧带动：成交人数增长22%、收入增长26%，利润增量占整体增量的约50%（+617万），是H1利润改善的最大贡献区域。南欧（+19%/+24%）、北欧（+25%/+23%）、英爱（+13%/+32%）同步增长。东欧+巴尔干出现下滑（-16%/-9%），需关注。渠道侧，电商已成为核心成交来源，其中携程占比44%；分销结构向电商倾斜，电商整体占比已过半。

国旅品牌
成交端收入增长主要来自单客收入提升12%，并非成交规模扩张。区域上，南欧和北欧分别增长57%、53%，是主要增长来源；线下门店成交端收入增长16%，对基本盘形成支撑。与此同时，西欧收入下滑17%，需尽快明确产品、价格或渠道端的具体原因。

大盘格局
双品牌整体份额由39%提升至46%，整体跑赢大盘。其中，翔龙品牌份额提升9个百分点，是份额增长的主要贡献；国旅品牌份额下降3个百分点。其他供应商份额由60%降至53%，市场份额进一步向双品牌集中。

3. 增长质量

翔龙品牌
增长质量较前期明显改善。毛利率由2%提升至6%，主要区域均实现盈利，单客毛利由437元提升至1,415元；规模增长与利润改善同步发生。
下一步需结合成本明细、退改投诉、复购及团队交付数据，判断当前改善能否沉淀为稳定的经营能力。

国旅品牌
经营表现呈现明显的结构性分化：成交端收入增长5%，但人数下降6%，收入增长主要依赖客单价提升。区域端，南欧、北欧增长，西欧及东欧+巴尔干下滑，产品区域结构仍需优化。
线上成交端人数下降14%，是当前规模恢复的主要压力点。北京国旅品牌在携程平台UV逆势增长32%，CR从0.45%提升至0.56%（+0.11pp），流量获取效率和转化效率均优于大盘；但大盘UV下滑57%，线上整体流量收缩仍对成交规模形成制约。

4. 品牌经营判断

翔龙品牌：H2转向提升经营效率
西欧产品实现突破，电商与出境社协同承接成交，分销增长基础已形成。H2重点从"做增量"转向"提质量"：一是提高机位使用效率和资源收益；二是优化渠道结构，降低对单一平台的依赖；三是通过复购、退改投诉和团队交付表现，验证产品与渠道增长的稳定性。

国旅品牌：线下稳基本盘，线上及区域供给需加快修复
线下门店成交端收入增长16%，仍是当前稳定规模的核心支撑；北京国旅品牌在携程平台UV逆势增长，说明线上仍具备流量获取基础。当前短板集中在线上成交下滑、区域产品供给不均及成交人数承压。H2应围绕淡季产品线、重点区域供给、线上转化及线下重点省份市占率开展修复；暑期阶段则以团队交付和服务保障为首要任务。

H2经营策略与工作重点

翔龙品牌：保持增长势能，进一步提升经营质量。
翔龙品牌上半年整体经营表现有所改善，规模、收入及盈利能力呈现积极变化，部分区域经营效率得到提升，西欧区域盈利能力也有阶段性改善。H2阶段不宜单纯追求规模增长，应在保持业务稳定发展的基础上，进一步关注机位资源利用效率、渠道投入产出和产品交付质量，持续验证增长的可持续性，推动业务从规模增长向质量增长转变。

国旅品牌：优先稳规模、补供给、提市占。
国旅品牌当前收入增长主要由客单提升带动，成交人数和线上成交仍存在压力。H2应以暑期团队交付为基础，重点补强淡季产品供给和重点区域产品线，提升线上转化效率，并推动线下重点省份及线上重点区域的市占恢复。

共同经营要求：增长必须以利润、交付和客户体验为基础。
翔龙品牌后续重点是持续验证增长质量，提升规模与盈利、交付能力之间的匹配度；国旅品牌后续重点是恢复成交规模和区域竞争力。两品牌均需持续关注利润表现、退改投诉、交付稳定性及客户反馈，避免单纯以收入或人数衡量经营成果。
