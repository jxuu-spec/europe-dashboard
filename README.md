## 二、部署方案（推荐）

### 方案A：GitHub Pages（免费 · 长期稳定）

1. **创建GitHub仓库**
   - 访问 https://github.com/new
   - 仓库名：`europe-dashboard`
   - 设置为 Public
   - 勾选 "Add a README file"

2. **上传文件**
   - 进入仓库 → 点击 "Add file" → "Upload files"
   - 上传 `deploy/` 目录下的所有文件（拖拽或选择）
   - Commit message: `Deploy v1.2.9 - 7.25-8.07双周经营分析`

3. **开启GitHub Pages**
   - 进入仓库 Settings → Pages（左侧菜单）
   - Source 选择 "Deploy from a branch"
   - Branch 选择 `main` / `master`，文件夹选择 `/ (root)`
   - 点击 Save

4. **访问地址**
   - 等待1-2分钟后，访问 `https://你的用户名.github.io/europe-dashboard/`
   - 入口页面会显示所有历史版本
   - 点击 "最新版本" 即可查看当前双周会看板

### 方案B：Cloudflare Pages（免费 · 国内访问快）

1. 访问 https://dash.cloudflare.com/ → Pages
2. 点击 "Create a project" → "Upload an asset"
3. 拖拽 `deploy/` 目录下的所有文件上传
4. 项目名设为 `europe-dashboard`
5. 部署完成后获得 `https://europe-dashboard.pages.dev/` 地址

### 方案C：Vercel（免费 · 自动部署）

1. 访问 https://vercel.com/new
2. 导入GitHub仓库，或选择 "Upload" 直接上传文件
3. 框架预设选择 "Other"
4. 部署完成后获得 `https://europe-dashboard.vercel.app/` 地址

## 三、历史版本保留机制

每次更新时，只需重复以下步骤：

1. 保留所有旧的HTML文件（不删除）
2. 把新的 `例会经营数据看板.html` 上传到仓库根目录（覆盖旧版）
3. 同时上传一份带版本号的归档文件（如 `例会经营数据看板_v1.3.0_20260823.html`）
4. 更新 `index.html` 入口页面，把最新版本移到顶部

这样访问者既可以看到最新数据，也可以随时查看历史版本。
